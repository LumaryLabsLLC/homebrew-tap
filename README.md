# Lumary Labs Homebrew Tap

Official [Homebrew](https://brew.sh) tap for [Lumary Labs](https://lumarylabs.com) apps.

## Install

```sh
brew install --cask lumarylabsllc/tap/lumary-cam
```

## Apps

| Cask | App | Description |
| --- | --- | --- |
| `lumary-cam` | [Lumary Cam](https://lumarylabs.com/lumarycam) | Local-first virtual camera with real-time enhancement and iPhone-over-USB-C support |

Casks are updated automatically by the release pipeline. Direct downloads are
also available from [GitHub Releases](https://github.com/LumaryLabsLLC/lumarycam-releases/releases).
