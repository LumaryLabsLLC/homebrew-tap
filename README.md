# Lumary Labs Homebrew Tap

Official [Homebrew](https://brew.sh) tap for [Lumary Labs](https://lumarylabs.com) apps.

## Install

```sh
brew install --cask lumarylabsllc/tap/lumary-cam
brew install --cask lumarylabsllc/tap/hyperkeys
```

## Apps

| Cask | App | Description |
| --- | --- | --- |
| `lumary-cam` | [Lumary Cam](https://lumarylabs.com/lumarycam) | Local-first virtual camera with real-time enhancement and iPhone-over-USB-C support |
| `hyperkeys` | [HyperKeys](https://github.com/LumaryLabsLLC/hyperkeysapp) | Turn Caps Lock into a Hyper key for app, window and menu shortcuts |

The Lumary Cam cask is updated automatically by its release pipeline. Direct
downloads are also available from GitHub Releases for
[Lumary Cam](https://github.com/LumaryLabsLLC/lumarycam-releases/releases) and
[HyperKeys](https://github.com/LumaryLabsLLC/hyperkeysapp/releases).
